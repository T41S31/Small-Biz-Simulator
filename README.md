# Small Biz Simulator

小規模事業者向けの経営シミュレーションWebアプリです。

## Background

小規模事業者や開業予定者にとって、
「損益分岐点」「変動費率」「限界利益率」といった
経営指標は重要である一方、会計知識がないと理解しにくい
という課題に着目しました。

## Concept

「経営数字が苦手でも、今日必要な売上と客数が分かる」

## Target User

- 小規模店舗経営者
- 個人事業主
- 開業予定者
- 会計知識が少ない人

## Features

- 変動費率計算
- 限界利益率計算
- 損益分岐点計算
- 1日必要売上計算
- 必要客数計算
- レスポンシブ対応
